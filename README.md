# DIGITALIZATION-PROJECTS
Repositorio donde voy subiendo proyectos sobre Digitalización Aplicada al Sector Productivo.

En cada proyecto parto de un caso concreto, una empresa o una organización con un problema, y analizo qué tecnologías habilitadoras digitales (THD) se le pueden aplicar, como la nube, el IoT, la inteligencia artificial o el Big Data, qué beneficios tendrían y qué impacto y riesgos supondrían.
